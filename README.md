## ⚡ What is woopixpad?

**woopixpad** is an advanced next-generation launchpad and automated market-making protocol built on Solana. It reimagines token launches by aligning incentives between creators, traders, and long-term holders:

- **Hold-to-Earn Rewards**: Every buy and sell pays a 1.5% fee on-chain. 0.6% of every trade goes directly to token holders. Hold longer, get a bigger slice of trading volume.
- **Multi-Pair Launchpad**: Launch coins paired with anything — SOL, Bitcoin (WBTC), Gold, USD1, BONK, PENGU, and more.
- **Fair Blocks**: 60-second batch opening window where every buy gets the exact same price. Zero snipers, zero sandwich bots.
- **Exit Queue Protection**: Whales sell into buys in an orderly queue, preventing violent chart dumps.
- **Ticker Protection**: Copycats pay 1 SOL fee directly to original token holders.
